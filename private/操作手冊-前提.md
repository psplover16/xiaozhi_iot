## 第二部分：電源分配、星型接地與全機接線總表

### 1. 雙軌電源分配架構（Power Architecture）

本系統由 **18650 電池座 V3 模組** 提供兩組獨立穩壓輸出，嚴格執行**動力與邏輯分離**，避免功放與 Wi-Fi 瞬時大電流拉垮感測器與麥克風基準電壓：

1. **`4.86V` 動力軌（V3 `5V` 輸出端）**：
   * **總出口濾波**：並聯 `470 µF 電解電容` ＋ `104K (100 nF) 陶瓷電容` 接至動力地（`GND_A`）。
   * **功放供電**：直接拉至 `MAX98357A` 的 `VIN` 腳（腳邊再緊貼並聯 `470 µF 電解電容` ＋ `104K (100 nF) 陶瓷電容` 對 `GND_A`）。
   * **主控供電**：經一組 **2-Pin 跳線帽** 接至 `ESP32` 的 `5V / VBUS` 腳。
     > **燒錄安全操作**：使用 Type-C 連接電腦燒錄程式或看 Serial 日誌時，**務必先拔除這顆 `4.86V → ESP32 5V` 跳線帽**（或關閉 V3 電源），防止電腦 USB 的 5V 倒灌進 V3 升壓晶片。
2. **`3.33V` 邏輯與感測軌（V3 `3.3V` 輸出端）**：
   * **總出口濾波**：並聯 `470 µF 電解電容` ＋ `104K (100 nF) 陶瓷電容` 接至數位地（`GND_B`）。
   * **嚴禁短接主控 `3V3`**：`ESP32` 板載的 `3V3` 腳由其內部 LDO 產生，**絕對不可與 V3 的 `3.33V` 輸出對接**；僅在 `ESP32` 的 `3V3` 與 `GND` 腳旁就近並聯 `100 µF 電解電容` ＋ `104K (100 nF) 陶瓷電容`（接 `GND_A`）吸收 Wi-Fi 發射脈衝。
   * **麥克風獨立 RC 濾波支路**：由 V3 `3.33V` 串聯一顆 `47 Ω 碳膜電阻` 後，對潔淨感測地（`GND_C`）並聯 `10 µF 電容` ＋ `104K (100 nF) 陶瓷電容`，產生潔淨電源節點 **`VDD_MIC`（兩顆麥克風工作下實得約 `3.20V`）**，專供兩顆 `INMP441` 使用。

### 2. 三支路星型接地架構（Star Grounding）

在洞洞板上選定靠近 18650 V3 負極出口的單一焊點作為**全機唯一星型接地點（`GND_STAR`）**，以粗裸銅線放射狀分出三條互不交錯的獨立地線支路，徹底杜絕地迴路串擾（Ground Loop）：

```text
                       ┌──► 【支路 A：動力地 GND_A】
                       │     • MAX98357A (GND + 470µF + 104K)
                       │     • ESP32 電源地 (GND + 3V3端 100µF + 104K)
                       │
[18650 V3 負極] ──► [GND_STAR] ──► 【支路 B：數位周邊地 GND_B】
                   (唯一匯流點)    • 普通標準 SD 卡模組 (GND + 100µF + 104K)
                       │          • 0.96" OLED (GND + 10µF + 104K)
                       │          • 模式按鍵 (GND + 104K)
                       │
                       └──► 【支路 C：潔淨類比與感測地 GND_C】
                             • 2x INMP441 (GND + RC濾波 10µF + 各顆 104K + 100kΩ下拉 + Mic1 L/R)
                             • ChronoDot V2.0 / AT24C256 / GY-30 / DHT22 (各自 GND + 104K)
```

### 3. 洞洞板空間佈局與聲學隔離規範

焊接前規劃零件擺位時，必須符合以下 4 項實體與聲學約束：

1. **雙 `INMP441` 線性陣列間距 `65 mm`**：
   * 兩顆麥克風的**金色圓形收音孔中心距離必須精準為 `65 mm`**（在 `2.54 mm` 間距的洞洞板上約間隔 **25.5 ～ 26 個孔位**），且兩顆收音孔朝向同一方向，以匹配 `ESP-AFE` 雙麥波束成形演算法。
2. **喇叭機械懸空隔離**：
   * `8Ω 2W` 喇叭發聲時的殼體震動若傳導至洞洞板，會干擾板上 MEMS 麥克風收音。**喇叭嚴禁直接用螺絲或熱熔膠硬鎖在主洞洞板上**，必須使用泡棉膠墊、矽膠腳墊懸空隔離，或獨立固定於外殼音腔。
   * 功放至喇叭的兩條導線務必**緊密互絞（雙絞線）**，抵消 Class-D 高頻切換輻射干擾。
3. **天線淨空區**：
   * `ESP32` 頂部的陶瓷/PCB 天線端應朝洞洞板邊緣伸出，天線正下方與周圍 `15 mm` 內不可走裸銅線或放置金屬外殼零件（如 SD 卡座、電池座）。
4. **高低頻走線隔離**：
   * `MAX98357A` 與喇叭線安排在洞洞板一側，兩顆 `INMP441` 安排在另一側，訊號線不可平行貼近走線。

### 4. 焊前模組確認（全模組保持原裝完整，免拆任何元件）

在將模組插上洞洞板排母之前，請確認以下 3 項要點：

1. **全機模組 100% 保持原裝完整**：
   * `0.96" OLED`、`RTC I2C DS3231 ChronoDot V2.0`、`AT24C256`、`GY-30` 這 4 塊 I2C 模組**均無需拆除任何板載電阻或二極體**。四塊模組原裝板載上拉電阻並聯後等效阻值約 `1.2 kΩ ~ 1.6 kΩ`，完全符合 `400 kHz` I2C 電氣規範，因此洞洞板主線上**不再額外焊 `4.7 kΩ` 上拉電阻**。
2. **`ChronoDot V2.0` 電池使用說明**：
   * 本模組無充電電路，先不安裝鈕扣電池亦可正常計時運作（斷電後時間重置，切換至模式 1 連網後即透過 NTP 自動校時）；日後加裝電池時，請依模組背面電池座尺寸購買**標準不可充電 `CR1632` 或 `CR2032` 鋰鈕扣電池**（切勿使用充電式 `LIR` 電池）。
3. **普通標準 SD 卡模組雙電源腳確認**：
   * 大卡 SD 模組排針同時標有 `3.3V` 與 `5V`。本設計**僅連接模組的 `3.3V` 腳至 V3 `3.33V` 軌**，模組上的 **`5V` 腳保持完全空接**（繞過板載 AMS1117 穩壓器壓降）。
