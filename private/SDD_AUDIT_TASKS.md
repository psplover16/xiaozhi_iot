# Xiaozhi IoT 程式碼與新版 SDD 自主比對任務書

## AI 執行者最高守則（必須嚴格遵守，禁止中斷）
1. **全自動連續執行，禁止中途停下詢問使用者**：你必須一口氣依照順序執行完 `Task 1` → `Task 2` → `Task 3` → `Task 4` → `Task 5` → `Task 6` → `Task 7` → `最終總結`，中途**絕對不要**停下來問「是否繼續」或等待確認。
2. **絕對禁止修改任何原始碼**：你只能讀取與搜尋專案現有程式碼；唯一允許建立與寫入的檔案是專案根目錄的 `SDD_DIFF_REPORT.md`。
3. **逐任務即時寫入報告（防遺忘機制）**：每完成一個 Task 的程式碼搜尋與比對，**立刻**將該 Task 的比對結果「附加（Append）」寫入 `SDD_DIFF_REPORT.md` 末端，寫完後立刻接著執行下一個 Task。
4. **精準標註位置與誠實回報疑惑**：每一項差異、缺漏或模糊不清的實作，都必須標註實際的「檔案路徑」與「函式名稱／行號」；遇到不確定的邏輯直接列入「疑惑與待確認項目」，不可自行猜測腦補。

## Task 1：硬體模組、I2C 位址與 GPIO 腳位配置比對
* **搜尋關鍵字**：`GPIO`、`DHT22`、`SHT41`、`SGP41`、`BH1750`、`GY-30`、`DS3231`、`AT24C256`、`INMP441`、`MAX98357`、`ledc`、`pwm`、`0x23`、`0x68`、`0x50`、`0x3C`
* **新版 SDD 規格標準**：
  1. **主控模組**：ESP32-S3-N16R8（雙核心 240MHz、16MB NOR Flash、8MB Octal PSRAM 80MHz）。
  2. **溫濕度感測器變更**：必須完全廢棄 `DHT22`（原 `GPIO 14` 應釋出），改用 `SHT41`（接在 I2C0 匯流排，並提供溫濕度數據給 SGP41 做環境補償）。
  3. **新增空氣品質感測器**：必須包含 `SGP41`（接在 I2C0 匯流排，偵測 VOC 指標與 NOx 指標）。
  4. **移除背光 PWM 電路**：必須完全刪除原 `GPIO 2` 的 LEDC PWM 背光調光電路與程式碼；`SSD1306`（0.96 吋 `128x64`，I2C0 位址 `0x3C`）改為直接透過 OLED 內部對比度指令調整亮度。
  5. **其他 I2C0 裝置**：`GY-30/BH1750`（`0x23`，連續高解析度指令 `0x10`）、`DS3231`（`0x68`）、`AT24C256`（`0x50`）。
  6. **SPI2 SD 記憶卡模組（標準大卡座板）**：`MOSI=GPIO 11`、`MISO=GPIO 13`、`CLK=GPIO 12`、`CS=GPIO 10`，掛載 FATFS `/sdcard`。
  7. **音訊 I2S 與按鍵腳位**：
     - 雙 `INMP441`（I2S 輸入）：`BCLK=GPIO 4`、`WS=GPIO 5`、`DIN=GPIO 6`（左右雙聲道立體聲採集）。
     - `MAX98357A`（I2S 輸出）：`BCLK=GPIO 15`、`LRC=GPIO 16`、`DOUT=GPIO 7`。
     - 實體模式控制按鍵：`GPIO 1`（啟用內部上拉電阻，低電位為按下）。
* **輸出要求**：將仍殘留 DHT22 或 GPIO 2 背光 PWM 的位置、尚未實作 SHT41/SGP41 的部分、腳位或位址不符處，追加寫入 `SDD_DIFF_REPORT.md`。

## Task 2：資料儲存分工、延壽層級與補傳順序比對
* **搜尋關鍵字**：`nvs`、`eeprom`、`AT24C256`、`psram`、`sdcard`、`/sdcard/logs`、`.bin`、`0x50`
* **新版 SDD 規格標準**：
  1. **系統設定檔存放位置變更**：所有系統設定參數必須專存於「機身內建斷電記憶晶片設定區（ESP32 內部 NVS）」，**嚴禁**在 NVS 寫入任何高頻環境感測數據。
  2. **AT24C256 全容量釋放**：移除原本存放在 AT24C256 的系統設定區，整顆 32KB（32,768 Bytes，64-Byte 頁對齊與環形平均磨損，單輪約 2,040 筆）全數開放給離線環境感測紀錄。
  3. **感測資料儲存優先層級（不可顛倒）**：
     `第 1 層：高速暫存記憶體 PSRAM（512KB / 最多 32,768 筆）` ＞ `第 2 層：雲端伺服器` ＞ `第 3 層：AT24C256（全 32KB）` ＞ `第 4 層：SD 記憶卡（/sdcard/logs/YYYYMMDD.bin）`。
     （重點檢查：舊版是否仍寫成「離線先寫 SD 卡、無卡才寫 AT24C256」，必須改為「離線先寫 AT24C256，滿門檻才整批倒入 SD 卡」）。
  4. **AT24C256 接近滿載警告與整批倒入 SD 卡流程**：
     - 達設定門檻（預設 `90%`，網頁模式可調）時，立即在「OLED 螢幕（螢幕開啟狀態下）」與「網頁模式即時監控介面」顯示警告。
     - 將 AT24C256 內所有離線紀錄**嚴格按時間先後順序（最舊到最新）**讀出，以**附加模式（Append，絕不覆蓋既有資料）**寫入 `/sdcard/logs/YYYYMMDD.bin`（UTC+8），確認寫入成功後**立即清空 AT24C256 歸零**。
     - 若未插 SD 卡或 SD 卡異常/已滿，保留警告且**不可刪除** AT24C256 資料。
  5. **恢復聯網後的自動補傳順序（最舊資料優先）**：
     `① 先清空 SD 卡未同步 .bin 日誌` → `② 再清空 AT24C256 剩餘離線紀錄` → `③ 最後恢復 PSRAM 即時上傳`（若網頁模式的「雲端伺服器連線開關」為關閉，則暫停所有上傳與補傳）。
* **輸出要求**：將儲存層級順序差異、設定檔仍存於 AT24C256、寫入覆蓋風險或補傳順序不符處，追加寫入 `SDD_DIFF_REPORT.md`。

## Task 3：小智 AI 語音互動、獨立錄音功能與音訊防破音比對
* **搜尋關鍵字**：`vad`、`wake`、`barge`、`tts`、`wav`、`mp3`、`i2s`、`volume`、`/sdcard/rec`、`record`
* **新版 SDD 規格標準**：
  1. **免按鍵喚醒與多輪對話**：離線語音喚醒（如「你好小智」），一問一答後短暫保持聆聽支援連續追問。
  2. **預錄防漏字緩衝（Pre-roll Buffer）**：待機監聽時在 PSRAM 維持 `300 ~ 500ms` 滾動循環緩衝區；當人聲音量高於動態噪音門檻持續 `150ms` 觸發時，自動將預錄聲音接在最前面；安靜持續 `800ms` 或達上限結束說話。
  3. **雲端 AI 對話語音暫存**：僅在 PSRAM 暫存（用完即清空，絕不存檔），單次時間上限可透過網頁模式調整（範圍 `5 ~ 60 秒`，預設 `15 秒`）。
  4. **隨時打斷插話（Barge-in）**：播放時開口說話、喊停止或短按實體按鍵，必須在 `50ms` 內中斷播放。
  5. **新增獨立錄音功能（正式存檔於 SD 卡）**：
     - 與 AI 對話緩衝完全獨立，透過離線語音指令觸發（喊出「開始錄音」啟動、「停止錄音」結束存檔）。
     - 透過 PSRAM 串流寫入 SD 卡，預設資料夾 `/sdcard/rec/`、檔名自動以時間命名（如 `20261124_143000.wav`，不覆蓋）、格式支援 `WAV` 或 `MP3`（預設 `WAV`）、單次上限 `1 ~ 60 分鐘`（預設 `10 分鐘`），皆可透過網頁模式調整。
     - 錄音途中若 SD 卡剩餘空間低於設定警告門檻，自動停止並安全存檔。
  6. **喇叭啟動播放 5 種情境與防破音**：
     - 5 種情境：(1) 雲端 TTS 回覆 (2) 離線／關閉雲端時觸發對話的本地提示音 (3) 離線語音指令回饋（含查詢溫濕度、查詢 SGP41 空氣品質、開始/停止錄音、開關網頁模式） (4) SD 卡本地音樂 (5) SGP41 空氣品質超標警示音。
     - 支援 WAV/MP3 及 `16k / 22.05k / 44.1k / 48kHz` 動態取樣率切換、單聲道自動轉雙聲道、`0% ~ 100%` 無段音量（與網頁同步並存 NVS）、軟體數位防削波（Soft-Clipping）防破音及硬體增益匹配。
* **輸出要求**：將缺少 Pre-roll 緩衝、缺少獨立錄音功能、缺少防削波或播放情境缺漏處，追加寫入 `SDD_DIFF_REPORT.md`。

## Task 4：環境監測、SGP41 警告、背景統計與 NTP 對時比對
* **搜尋關鍵字**：`SHT41`、`SGP41`、`BH1750`、`ntp`、`sntp`、`stdtime`、`DS3231`、`trend`、`voc`、`nox`
* **新版 SDD 規格標準**：
  1. **三個感測器獨立採樣週期**：`SHT41`（溫度 °C、濕度 % RH）、`SGP41`（VOC 指標、NOx 指標，需帶入 SHT41 溫濕度補償）、`GY-30`（照度 lux）各自擁有獨立的採樣間隔秒數（可在網頁模式分別設定），不可共用單一採樣間隔。每筆紀錄含時間戳記、感測數值、感測器與網路狀態標記、校驗碼。
  2. **SGP41 空氣品質查詢與雙重超標警告**：
     - 支援透過離線語音指令或雲端 AI 對話查詢並播報當下 VOC 與 NOx 狀態。
     - 當 VOC 或 NOx 超過網頁模式設定的警戒門檻時，**同時觸發**「OLED 螢幕顯示空氣品質警告圖示」＋「喇叭播放警示提示音」。
  3. **背景環境趨勢統計**：在 PSRAM 歷史視窗時數內，計算溫度、濕度、照度、SGP41（VOC / NOx）的**最大值、最小值、平均值**，以及**溫度與 SGP41 指標的變化趨勢（上升 / 持平 / 下降）**。
  4. **UTC+8 與 NTP 自動對時**：
     - 全系統統一 UTC+8；開機讀取 DS3231。
     - 連上 Wi-Fi 後，連線至網頁模式設定的 NTP 伺服器（出廠預設並預填 `time.stdtime.gov.tw`，備援 `tock.stdtime.gov.tw`、`pool.ntp.org`；若清空儲存自動還原預設），同步後回寫修正 DS3231。
* **輸出要求**：將採樣間隔未獨立、SGP41 警告或趨勢統計缺漏、NTP 寫死無法自訂等差異，追加寫入 `SDD_DIFF_REPORT.md`。

## Task 5：OLED 螢幕顯示配置與對比度自動調光比對
* **搜尋關鍵字**：`SSD1306`、`oled`、`display`、`contrast`、`lux`、`u8g2`、`lvgl`、`adafruit`
* **新版 SDD 規格標準**：
  1. **畫面規格**：128x64 單色自發光 OLED，每秒刷新 10 次（10 FPS）。
  2. **頂部狀態列**：
     - 左側：同時獨立反映雙軌狀態——顯示 Wi-Fi 連線狀態（`在線` / `離線`），開啟網頁模式時在後方附加顯示 `[網頁模式]` 標記（若雲端連線開關設為關閉，亦顯示對應狀態標記）。
     - 右側：未同步離線資料總筆數 ＋ 警告圖示（AT24C256 滿載 / SD 卡低空間 / SGP41 超標）。
  3. **中央主視覺區**：待機顯示大字體時間（`HH:MM:SS`）；喚醒小智顯示互動狀態（待機中/聆聽中/思考中/說話中）；獨立錄音期間顯示錄音進行中與已錄製時間。
  4. **底部資訊列（雙頁自動輪播）**：每 `3 ~ 5 秒` 自動輪播切換：
     - 第 1 頁：室內溫度（°C）、相對濕度（% RH）、光照度（lux）。
     - 第 2 頁：SGP41 空氣品質指標（VOC 指標、NOx 指標）。
  5. **環境光自動調光**：無外部 PWM，依 GY-30 照度平滑漸變濾波後直接控制 OLED 面板內部對比度（`< 20 lux` 夜間護眼低對比、`20 ~ 300 lux` 線性平滑、`> 300 lux` 最高對比度）。
* **輸出要求**：將狀態列未呈現雙軌狀態、底部未輪播 SGP41、錄音無畫面指示或調光方式不符處，追加寫入 `SDD_DIFF_REPORT.md`。

## Task 6：雙軌獨立狀態、網頁模式（監控＋17 項設定）與按鍵手勢比對
* **搜尋關鍵字**：`Xiaozhi-Setup`、`192.168.4.1`、`xiaozhi.local`、`httpd`、`WebServer`、`AP_STA`、`button`、`GPIO_NUM_1`、`factory`
* **新版 SDD 規格標準**：
  1. **雙軌獨立狀態（純粹區分，不可互斥）**：
     - 狀態維度一：`有無連上 Wi-Fi`（在線 / 離線，未連上時背景每 30 秒自動重連，手動強制離線除外）。
     - 狀態維度二：`有無開啟網頁適配模式（簡稱網頁模式）`（ON / OFF）。
     - 必須支援在「已連上 Wi-Fi（在線運作中）」的同時開啟「網頁模式」（使用 `WIFI_AP_STA` 混合模式），且關閉「雲端伺服器連線開關」時，**網頁模式依然正常開啟運作**。
  2. **網頁模式進出方式**：
     - 開啟：首次開機無 Wi-Fi 紀錄（或長按 10 秒恢復原廠設定後）自動開啟、實體按鍵「長按 3 秒」、或離線語音指令（「開啟網頁模式」）。
     - 連線：連上免密碼熱點 `Xiaozhi-Setup`（自動彈窗或 `http://192.168.4.1`），或已連家用 Wi-Fi 時透過同區網 IP / `http://xiaozhi.local` 直連。
     - 關閉：網頁按下「儲存設定」寫入 NVS 後自動關閉；或透過長按 3 秒、離線語音指令（「關閉網頁模式」）、網頁「關閉按鈕」手動關閉。
  3. **網頁模式即時監控儀表板（Live Dashboard）**：
     - 即時顯示並定時自動刷新：SHT41（溫度、濕度）、GY-30（照度）、SGP41（VOC 指標、NOx 指標）、Wi-Fi 連線狀態與區網 IP、目標熱點 SSID、AT24C256 已使用 % / 目前筆數 / 滿載警告提示、SD 卡掛載狀態 / 總容量與剩餘 MB / 低空間警告提示。
  4. **網頁模式 17 項可調參數（全存 NVS 且首次開啟預填預設值）**：
     (1) Wi-Fi SSID（最長 31 字元） (2) Wi-Fi 密碼（最長 63 字元） (3) 雲端伺服器 API URL（最長 127 字元） (4) 雲端伺服器連線開關（開啟/關閉，關閉時停止上傳/補傳/AI 對話並轉入離線儲存，但網頁模式仍正常開啟運作） (5) NTP 伺服器網址（預填 `time.stdtime.gov.tw`） (6) SHT41 採樣間隔（秒） (7) SGP41 採樣間隔（秒） (8) GY-30 採樣間隔（秒） (9) 記憶體歷史視窗時數（小時） (10) AT24C256 容量警告與轉存門檻（%，預設 `90%`） (11) SD 卡剩餘空間警告門檻（MB） (12) SGP41 空氣品質警戒門檻（VOC/NOx） (13) 喇叭音量大小調整（`0% ~ 100%`，與語音同步並斷電記憶） (14) 小智單次對話語音暫存上限（`5 ~ 60 秒`，預設 `15 秒`） (15) 獨立錄音存放資料夾路徑（預設 `/sdcard/rec/`） (16) 獨立錄音儲存檔案格式（`WAV` / `MP3`，預設 `WAV`） (17) 獨立錄音單次時間上限（`1 ~ 60 分鐘`，預設 `10 分鐘`）。
  5. **實體模式控制按鍵（GPIO 1）完整手勢**：
     - 開機瞬間按住 `> 0.3 秒`：進入互動式硬體與功能自檢測試選單。
     - 運行中「短按 1 下」：喇叭播放中優先作為立即停止播放鍵；待機時手動切換 Wi-Fi 連線（強制離線 ↔ 恢復自動連線）。
     - 運行中「長按 3 秒」：手動開啟或關閉「網頁模式」。
     - 運行中「長按 10 秒」：恢復原廠預設值（清空 NVS 自訂參數還原預設並自動開啟網頁模式）。
* **輸出要求**：將 Wi-Fi 與配網互斥寫死、缺少雲端獨立開關、網頁缺少監控或 17 項設定欄位、按鍵手勢不符處，追加寫入 `SDD_DIFF_REPORT.md`。

## Task 7：硬體異常容錯與最終總結整理
* **搜尋關鍵字**：`ESP_ERROR_CHECK`、`abort`、`esp_restart`、`mount`、`unmount`、`timeout`、`fallback`
* **新版 SDD 規格標準**：
  1. **單點故障隔離（嚴禁對外部模組或 SD 卡讀寫使用會觸發整機重啟的 `ESP_ERROR_CHECK`）**：
     - **SD 卡未插或運作中拔除**：離線數據仍寫入 AT24C256；達 90% 門檻發出警告並暫停轉存（絕不刪除 AT24C256 資料）；略過離線提示音；執行獨立錄音時提示無 SD 卡無法存檔。
     - **SHT41 讀取失敗**：沿用上次有效值並標記異常旗標，不中斷整體排程。
     - **SGP41 未連接或異常**：標記無效並略過超標警報，不影響溫濕度與光照採集。
     - **GY-30 未連接或異常**：照度預設為 `0`，螢幕維持預設安全對比度。
     - **DS3231 未連接或電池耗盡**：正常開機，連上 Wi-Fi 後透過 NTP 校時恢復時間。
